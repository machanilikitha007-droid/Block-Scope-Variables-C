# Block Scope of Variables in C

**Author:** M.Likitha

## Description

This program demonstrates block scope in C. A variable declared inside a block is accessible only within that block, while the variable declared outside remains accessible after the block ends.

## Concepts Used

- Block scope
- Local variables
- Nested blocks
- Variable shadowing

## How to Run

```bash
gcc block_scope.c -o block_scope
./block_scope
